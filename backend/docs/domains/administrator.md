# Administrator 集約

## 概要

管理画面にログインする管理者を表す集約。
メールアドレスとパスワードで認証し、ロールに応じた権限で操作を行う。

## ライフサイクル

- **登録**: 管理者が管理画面から手動で登録する
- **更新**: メールアドレス、パスワード、ロールの変更

## Administrator

### プロパティ

| プロパティ | 型 | 説明 |
|-----------|---|------|
| id | AdministratorId | 管理者ID |
| email | Email | メールアドレス。システム内で一意 |
| hashedPassword | String | ハッシュ化されたパスワード |
| role | AdminRole | 管理者ロール（admin / staff） |

### 不変条件

- Emailはシステム内で一意でなければならない

## Email（値オブジェクト）

### プロパティ

| プロパティ | 型 | 説明 |
|-----------|---|------|
| value | String | メールアドレス文字列 |

## 関連する集約

なし
